# Example: freelancer / consultant

## About me
- Name / role: Independent consultant, 3-6 clients at a time
- What I use Claude Code for: proposals, meeting notes, client deliverables, invoices follow-up
- How I like answers: short, bullet points, client name in the first line

## Extra rules
- Keep one folder per client. Never mix one client's material into another client's document.
- Meeting notes: separate "what they said" from "what we confirmed". Never present a claim as a fact.
- Proposals: reuse the closest past proposal first, then adapt. Tell me which one you started from.
- Anything waiting on a client reply goes to OPEN-ITEMS.md as **external**, with the date I asked.
- Every Friday when I ask "what's open?", list items waiting more than 7 days first.
